# CASELAB Robot Perception Team | 케이스랩 로봇 인지팀

안녕하세요! 저희는 CASELAB 로봇 인지팀(Robot Perception Team) 입니다. 저희는 로봇이 주변 환경을 스스로 인식하고 이해하여 지능적으로 행동할 수 있도록 만드는 인지(Perception) 기술을 연구하고 개발합니다.

## 우리가 연구하는 것 (Research Areas)

- 환경 인식 (Scene Understanding): 카메라, LiDAR 등 센서 데이터 기반의 객체 검출, 의미론적 분할, 장면 이해
- 3D 인지 및 맵핑 (3D Perception and Mapping): SLAM, 공간 재구성, 점군 처리
- 멀티모달 센서 융합 (Sensor Fusion): 이종 센서 데이터를 결합한 강건한 인식
- 딥러닝 기반 로봇 지능 (Learning-based Robotics): 자율 주행 및 조작을 위한 인지 모델 개발

## 하는 일 (What We Build)

저희는 연구 성과를 실제 로봇 플랫폼에 적용할 수 있는 형태로 개발합니다. 자율주행, 서비스 로봇, 산업용 로봇 등 다양한 응용 분야에서 로봇의 눈과 두뇌가 되는 인지 소프트웨어를 만듭니다.
